Sobre o Projeto
O Laboratório Liquid Glass é um projeto de interface web focado em explorar a intersecção entre o design translúcido (glassmorphism) e animações fluidas avançadas. O objetivo é criar uma experiência visual imersiva e moderna, utilizando distorções, desfoques intensos e reflexos dinâmicos.
🌟 Funcionalidades
￼ Fundo Animado Fluido: Bolhas de gradiente com animações complexas (⁠mix-blend-mode⁠ e ⁠blur⁠) que interagem entre si.
￼ Efeitos de Vidro (Glassmorphism): Diferentes níveis de profundidade (base, leve e pesado) com bordas iluminadas e desfoque de fundo.
￼ Morphing Blobs: Formas orgânicas animadas usando manipulação avançada de ⁠border-radius⁠.
￼ Botões Líquidos: Efeitos de hover que simulam o preenchimento de líquidos.
￼ Menu Overlay: Um menu popup (hambúrguer) imersivo em tela cheia.
￼ Totalmente Responsivo: Adaptado para dispositivos móveis e desktops.
💻 Tecnologias Utilizadas
￼ HTML5: Estrutura semântica.
￼ Tailwind CSS: Para o layout rápido, grid e responsividade.
￼ CSS3 Personalizado: Para as animações de morphing, keyframes fluidos e filtros avançados (⁠backdrop-filter⁠).
🚀 Como Usar
Como o projeto não utiliza frameworks complexos de JavaScript, a execução é extremamente simples:
1. Faça o clone ou baixe este repositório.
2. Dê um duplo clique no arquivo ⁠test.html⁠ para abri-lo diretamente em qualquer navegador moderno.

About the Project
The Liquid Glass Laboratory is a web interface project focused on exploring the intersection between translucent design (glassmorphism) and advanced fluid animations. The goal is to create an immersive and modern visual experience using distortions, intense blurs, and dynamic reflections.
🌟 Features
￼ Fluid Animated Background: Gradient blobs with complex animations (⁠mix-blend-mode⁠ and ⁠blur⁠) that interact with each other.
￼ Glassmorphism Effects: Different depth levels (base, light, and heavy) with illuminated borders and background blur.
￼ Morphing Blobs: Animated organic shapes using advanced ⁠border-radius⁠ manipulation.
￼ Liquid Buttons: Hover effects that simulate liquid filling.
￼ Overlay Menu: An immersive full-screen popup hamburger menu.
￼ Fully Responsive: Adapted for both mobile and desktop devices.
💻 Technologies Used
￼ HTML5: Semantic structure.
￼ Tailwind CSS: For rapid layout, grid, and responsiveness.
￼ Custom CSS3: For morphing animations, fluid keyframes, and advanced filters (⁠backdrop-filter⁠).
🚀 How to Use
Since the project doesn't use complex JavaScript frameworks, running it is extremely simple:
1. Clone or download this repository.
2. Double-click the ⁠test.html⁠ file to open it directly in any modern web browser.
